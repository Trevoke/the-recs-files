# Notes Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use recs-executing-plans to implement this plan task-by-task.

**Goal:** Three notes, one file each, under `notes/`, kept beside the
inspections.

**Architecture:** Each note is a plain text file holding its own name, kept
outside the SQLite file that holds the inspections.

**Tech Stack:** Plain text files and git.

---
