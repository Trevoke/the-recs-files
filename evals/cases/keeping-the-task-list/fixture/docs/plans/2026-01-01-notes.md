### Task 1: Note one

**Records:** UL-3: Field note; ADR-4: Keep field notes as plain text files under notes/

**Files:**
- Create: `notes/one.txt`

**Step 1: Create `notes/one.txt` containing `one`**

```bash
mkdir -p notes
printf 'one\n' > notes/one.txt
```

**Step 2: Commit**

```bash
git add notes/one.txt
git commit -m "Add note one"
```
