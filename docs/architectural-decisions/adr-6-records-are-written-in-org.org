* ADR-6 Records are written in org
:PROPERTIES:
:STATUS: Accepted
:END:
** Context
A record carries structured fields beside its prose: its status, the
records it supersedes, a workflow's actor and level. A workflow's steps
and extensions nest. Markdown has headings, lists and links, and structured
fields only through front matter, outside its own syntax.
** Decision
We will write records, their projections and the knowledge base in org,
for its property drawers, timestamps, footnotes and dynamic blocks, among
others.
** Consequences
A record's fields are property drawers, which the agent reads and changes
without parsing prose. Headings nest with meaning, so an extension sits
under its step. Timestamps, footnotes and dynamic blocks are there in the
same syntax when the records need them. A project that adopts the recs
files writes its records in org too. The skills stay in markdown, which
the skill format requires. Views that render only markdown show org less
well.
