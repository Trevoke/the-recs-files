* F-20261027-4zx7 The agent cites a record to the record keeper in its title's exact words, then names it again by its identifier
:PROPERTIES:
:STATUS: Accepted
:SUPERSEDES: [[./f-20261027-tkzn-the-agent-cites-a-record-to-the-record-keeper-in-its-titles-exact-words-with-every-section-it-means.org][F-20261027-tkzn: The agent cites a record to the record keeper in its title's exact words, with every section it means]]
:END:
1. When the agent first names a record in a reply to the record keeper, the
   agent shall cite it, giving the record's identifier and its title as the
   record's heading carries it.
2. When the agent names a record again in a reply that has cited it, the
   agent shall name it by its citation or by its identifier.
   - The one where the agent, having cited
     `F-20261027-v2mt: A sweep repoints or removes citations, and leaves plans as written`
     earlier in its reply, says that `F-20261027-v2mt §3` removes the
     citations of a retired record.
3. Where the agent names sections of a record to the record keeper, the
   agent shall name every section of that record the statement means
   together, after the identifier, each written out, in the record's order.
   - The one where the agent cites the fourth requirement of F-20261027-v2mt as
     `F-20261027-v2mt §4: A sweep repoints or removes citations, and leaves plans as written`.
   - The one where the agent cites the second and seventh requirements of
     F-20261027-v2mt as one citation,
     `F-20261027-v2mt §2, §7: A sweep repoints or removes citations, and leaves plans as written`.
4. When the agent tells the record keeper something of each of several
   sections of one record, the agent shall list each section by its number
   on a line of its own under the line that names that record and those
   sections, beside what it says of that section.
   - The one where the agent tells the record keeper what the first and third
     requirements of F-20261027-v2mt do, under
     `F-20261027-v2mt §1, §3: A sweep repoints or removes citations, and leaves plans as written`,
     on the lines "§1: a supersede repoints each citation to the successor"
     and "§3: a retirement removes each citation".
5. The agent shall set each citation it gives the record keeper, and each
   identifier it names a record by, in backticks.
6. The agent shall write each citation it gives the record keeper with no
   line break inside it.
7. Where a record the agent speaks of is not yet on disk, the agent shall
   name its sections by what they say, without numbers.
   - The one where the agent tells the record keeper that a successor not
     yet written would add a requirement that notifies the borrower.
8. When the agent quotes a record's text to the record keeper, the agent
   shall set the quote in a code block, exactly as the file holds it, under
   the line that names what it quotes.
   - The one where the agent quotes the second requirement of F-20261027-jtb9
     in a code block under
     `F-20261027-jtb9 §2: A superseded record names its successor`.
