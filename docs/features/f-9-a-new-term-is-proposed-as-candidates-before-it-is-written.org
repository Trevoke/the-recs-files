* F-9 A new term is proposed as candidates before it is written
:PROPERTIES:
:STATUS: Proposed
:END:
1. When a record change needs a term the ubiquitous language does not
   define, the agent shall propose candidate words and wait for the record
   keeper to agree to one.
2. When the agent proposes candidate words, the agent shall build them from
   existing terms first.
3. The agent shall offer no candidate that the ubiquitous language already
   defines.
4. The agent shall write no term into a record before the record keeper
   agrees to it.
5. The agent shall name each concept by one term, and by no synonym of it.
